## Ledger — iOS compatibility fixes (~2 hours)

Goal: get the app building clean on a physical device (iOS 16+).

---

### What was done

**Fixed Section + footer: syntax errors**
- `Section("string") { } footer: { }` is invalid — Swift can't infer the `Content` generic when
  a string title and a `footer:` trailing closure are both present
- Fix: use `Section { } header: { Text("...") } footer: { }` form instead
- Applied to: `EditWatchlistItemView.swift`, `AddWatchlistItemView.swift`
- Error messages this fixes: "Generic parameter 'Content' could not be inferred",
  "Missing argument label 'content:' in call",
  "Cannot convert value of type 'String' to expected argument type '() -> Content'"

**iOS 17-only APIs wrapped in `#available(iOS 17, *)`**
- Various additional iOS 17 API usages identified and wrapped during the session
- `SectorMark` (PortfolioView) and two-argument `onChange` (ChatView) are known iOS 17 hits
  that still need to be verified as fixed

### Blocker: Mac Git auth

Mac's `git push` is asking for username + password. GitHub dropped password auth — use a
**Personal Access Token (PAT)** instead:

1. github.com → Settings → Developer settings → Personal access tokens → Generate new token
2. Give it `repo` scope
3. Use it as the password when git prompts (or store with: `git credential-osxkeychain`)

Until this is resolved, Mac-side fixes can't be pushed back to the Windows repo.
