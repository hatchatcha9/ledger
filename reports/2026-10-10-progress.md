### Features added this session

**Multi-currency net worth (all three surfaces)**
- Dashboard, Accounts, and Widget all now agree on net worth
- PriceService fetches FX tickers (e.g. EURUSD=X) alongside asset prices
- Widget reads cached FX rates from shared UserDefaults (App Group)

**Ask Claude proxy (no user API key needed)**
- Railway Express server holds the Anthropic key server-side
- App sends proxy URL + app secret (both in gitignored Secrets.swift)
- 20 msg/day per-device rate limit; friendly error messages for 429/5xx
- Counter shown in chat nav bar ("X of 20 free today"), turns red at ≤3
- Counter increments on send (not on response) so it's always accurate

**iCloud sync**
- Switched to NSPersistentCloudKitContainer, container iCloud.com.hatchatcha9.ledger
- NSPersistentHistoryTrackingKey + remote change notifications enabled

**Per-asset price history chart**
- AssetDetailView now shows a 1-month daily close chart using SwiftUI Charts
- PriceService.fetchHistory() calls Yahoo Finance v8/finance/chart (interval=1d, range=1mo)
- Area fill, green/red by direction, axes hidden for clean look

**FI/RE multiplier exposed in Settings**
- Previously stored in @AppStorage but had no UI
- Settings > FI/RE Target: picker for 20×/25×/30×/33× with descriptions

**Global Recurring Transactions screen**
- AllRecurringView: all active rules across every account in one list
- Shows monthly-equivalent amounts and total committed expense/income summary
- Accessible from Settings > Budgets & Recurring
- Respects user's display currency (was hardcoded USD, now @AppStorage)

**Privacy policy**
- docs/privacy.html committed to repo, served via GitHub Pages
- https://hatchatcha9.github.io/ledger/privacy.html (live)
- Repo made public to enable free GitHub Pages

**Currency list fix**
- AddEditAccountView expanded from 7 G7-only currencies to 21
- Now matches the 21-currency list in Settings (SGD, HKD, KRW, AED, etc.)

**Dashboard empty state**
- New users now see "Add your first account →" card instead of six grey placeholders
- Tapping opens AddEditAccountView sheet directly from Dashboard

**Future-date transactions**
- Removed ...Date() upper bound on transaction date picker
- Users can now log upcoming bills and scheduled payments

**EditWatchlistItem**
- Watchlist items are now editable (symbol, name, target price, thesis notes)

**Spending velocity alert**
- Dismisses per-day (AppStorage key); fires when 50% above 3-month average

**Debt payoff planner**
- Avalanche/snowball methods, time-to-payoff estimate, appears for debt accounts

**Large amount confirmation**
- Warns when a transaction is 10× the category average (requires ≥3 data points)
